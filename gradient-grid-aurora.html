渐变网格 / Aurora Evolved

为英雄章节、背景和创意项目打造绚丽的渐变网格效果，营造梦幻而现代的视觉体验。

核心特性

绚丽渐变

使用多种颜色组合创建平滑过渡的渐变效果，为页面增添深度和视觉吸引力。

网格图案

添加微妙的网格背景，增强视觉层次感，使渐变效果更加突出。

动态效果

通过动画和过渡效果，使渐变和网格元素更加生动，提升用户体验。

应用场景

英雄章节

为网站首页或重要页面的英雄区域添加绚丽的渐变网格背景，立即吸引用户注意力。

创意项目

为创意作品集、艺术展示或设计项目添加独特的渐变网格效果，展现创意和个性。

品牌背景

为品牌网站或营销材料创建独特的渐变网格背景，增强品牌识别度。

活动页面

为活动宣传、产品发布或促销页面添加活力四射的渐变网格效果，提升活动氛围。

渐变效果展示

紫色系渐变
蓝绿色系渐变
橙红色系渐变
绿色系渐变

技术实现

CSS渐变

使用CSS linear-gradient()函数创建平滑的颜色过渡效果，支持多种颜色组合。

网格背景

通过CSS background-image属性创建网格图案，增强视觉层次感。

响应式设计

确保渐变网格效果在不同设备上都能正常显示，保持视觉一致性。

.gradient-bg {
    background: linear-gradient(135deg, #6366f1 0%, #8b5cf6 50%, #ec4899 100%);
}

.grid-pattern {
    background-image: 
        linear-gradient(rgba(255, 255, 255, 0.1) 1px, transparent 1px),
        linear-gradient(90deg, rgba(255, 255, 255, 0.1) 1px, transparent 1px);
    background-size: 20px 20px;
}

.aurora-border {
    position: relative;
}

.aurora-border::before {
    content: '';
    position: absolute;
    top: -2px;
    left: -2px;
    right: -2px;
    bottom: -2px;
    background: linear-gradient(45deg, #6366f1, #8b5cf6, #ec4899, #6366f1);
    border-radius: inherit;
    z-index: -1;
    animation: gradientAnimation 3s ease infinite;
}

@keyframes gradientAnimation {
    0% { background-position: 0% 50%; }
    50% { background-position: 100% 50%; }
    100% { background-position: 0% 50%; }
}
